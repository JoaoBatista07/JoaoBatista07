## 📦 Projeto em destaque

### [DSCommerce](https://github.com/JoaoBatista07/dscommerce)

API REST de e-commerce desenvolvida a partir do projeto do curso Java Spring Professional (DevSuperior), para praticar os fundamentos de back-end. **Em desenvolvimento.**

- Arquitetura em camadas (controller, service e repository)
- Segurança com Spring Security, OAuth2 e JWT
- Persistência com JPA/Hibernate e PostgreSQL, com validação de dados
- Roda localmente com banco H2, sem instalar nada além do Java

Próximo passo: construir o front-end e deixar back e front rodando juntos na máquina de quem baixar.
